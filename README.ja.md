## ご連絡の前に

メールを送る前に、まず本リポジトリの README と既存の GitHub Issues をご確認ください。

技術的な質問、不具合報告、利用上の問題については、GitHub Issue を作成していただくことを強く推奨します。そのほうが通常、より早く対応できます。

ご連絡の際は、以下の情報を含めてください。

- 氏名
- 所属
- お問い合わせの目的

共同研究や協力を希望する学生の方は、事前に指導教員の承認を得たうえで、メールの CC に指導教員を含めてください。
