## 联系我之前

在发送邮件之前，请先阅读本仓库的 README，并查看已有的 GitHub Issues。

对于技术问题、错误报告或使用相关问题，强烈建议优先提交 GitHub Issue，通常也会获得更快的回复。

联系我时，请在邮件中包含以下信息：

- 姓名
- 所属单位
- 咨询目的

希望开展合作的学生，请先获得导师同意，并在邮件中抄送导师。
